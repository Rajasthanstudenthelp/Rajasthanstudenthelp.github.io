# ISB Chat Premium Messenger

A secure, End-to-End Encrypted Web3 Messenger application.

## 🚀 Live Access
You can access the messenger here: [https://isbchat.github.io](https://isbchat.github.io)

## 🛡️ Features
- **End-to-End Encryption**: Your messages remain secure.
- **Web3 Identity**: Unique usernames for global access.
- **Status Updates**: Share moments with your encrypted network.
- **Secure Media Sharing**: Send photos, videos, and PDFs safely.
